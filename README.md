# Age of War (Bản làm lại bằng Raylib)

Một tựa game chiến thuật thủ thành lấy cảm hứng từ huyền thoại Age of War, được phát triển bằng C++ và thư viện đồ họa Raylib.

## 🎮 Hướng dẫn chơi

- **Mục tiêu:** Tiêu diệt nhà chính của đối phương trước khi nhà của bạn bị phá hủy.
- **Nâng cấp thời đại:** Tích lũy đủ điểm kinh nghiệm (EXP) để tiến lên thời đại mới (Stone Age -> Medieval Age -> Modern Age). Lính và tháp sẽ trở nên mạnh mẽ hơn!
- **Kỹ năng đặc biệt:** Sử dụng mưa thiên thạch (Meteor) để quét sạch lính địch khi cần thiết.

### Phím tắt:
- Phím `1`: Mua lính Cận chiến (Warrior / Knight / Soldier)
- Phím `2`: Mua lính Đánh xa (Archer / Crossbow / Sniper)
- Phím `3`: Mua lính Hạng nặng (Tank / Catapult / Battle Tank)
- Phím `T`: Xây tháp phòng thủ
- Phím `B`: Mua EXP bằng vàng
- Phím `E`: Nâng cấp thời đại (Evolve)
- Phím `SPACE`: Gọi mưa thiên thạch (Meteor)

## 🚀 Cách tải và cài đặt

1. Tải về file nén `AgeOfWar_Release.zip`.
2. Giải nén toàn bộ thư mục ra máy tính của bạn.
3. Chạy file **`game.exe`** để bắt đầu chơi.

**Lưu ý:** Bắt buộc phải để file `game.exe` cùng một chỗ với thư mục `assets` (chứa hình ảnh game) thì game mới hoạt động được bình thường.
